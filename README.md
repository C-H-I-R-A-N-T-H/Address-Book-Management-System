Address Book Management System
A menu-driven Address Book Management System developed using C
programming. The project helps manage contact details through a simple
console-based interface.

Features

1.Add and manage contact information


2.Search for contacts using phone number or email address

3.Edit and delete contact details

4.Display the contact list

5.Validate phone numbers and email addresses

6.Check for duplicate phone numbers and email addresses

7.Save and load contact information using file handling
Technologies and Concepts

1. C Programming
   
2.Structures

3.Arrays

4.Pointers

5.Strings and string-handling functions

6.Input validation

7.File handling
